Spentra

Know Your Money. Own Your Future.

Spentra turns your monthly income into a daily spending budget (income ÷ 30). Every payment you record reduces that day's remaining allowance.

Features
Single-account sign in (stored on this device, password salted and hashed)
Dashboard, Transactions, Analytics, Daily Budget, Savings Goals, Financial Score, Calendar, Settings
Automatic merchant categorisation that learns from your corrections
30-day budget cycles with optional carry-forward
Financial score that does not penalise essential spending
Light and dark themes, CSV export
Run it

Open index.html in any modern browser. No install or build step.

Notes
Frontend only. All data lives in the browser's localStorage.
No bank connection yet. Payments are entered manually.
Google sign-in and password reset need a backend and are not active.
Tech

HTML, CSS and vanilla JavaScript in a single file.
